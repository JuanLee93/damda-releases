# Damda (담다)

내 PC 안에서 돌아가는 개인용 사진/동영상 정리 프로그램입니다.

- 폴더를 스캔해서 중복을 걸러내고, 촬영일시 기준으로 `년/월` 폴더에 자동 정리
- 태그·즐겨찾기로 갤러리에서 찾아보기, 동영상 재생
- 사진은 외부 서버로 보내지 않고 PC 안에만 저장

## 받기

오른쪽 **[Releases](../../releases/latest)** 에서 최신 `Damda-<버전>.exe` 를 받아 실행하세요.

- Windows 10/11 64비트
- 관리자 권한 없이 설치됩니다 (프로그램: `%LOCALAPPDATA%\DamdaApp`, 데이터: `%LOCALAPPDATA%\Damda`)
- 새 버전이 나오면 앱이 알려줍니다. 받은 설치 파일을 실행하면 덮어 설치되고, 사진·설정·계정은 그대로 남습니다.
- 동영상 썸네일/재생에는 FFmpeg가 필요합니다. 앱의 설정 페이지에서 설치할 수 있습니다.

이 저장소는 설치 파일 배포용입니다.
